Inspect a DATEX II roadworks feed

Open or drop a DATEX II XML file (v2 or v3, plain or gzip-compressed), for example a roadworks or closure publication downloaded from a National Access Point.

The file is processed in your browser and is not uploaded.

Where to download a feed and what the checks mean: see the documentation.

What it checks
  • XML well-formedness, DATEX II version, publication type, namespaces and extensions
  • XSD validation against schema files you select
  • Heuristic profile checks (MDM roadworks profile, NDW)
  • Roadworks and closures with line geometry on the map; other location types are listed with a reason
  • Lane status (laneStatusCoded) against OSM lane tags
  • Closures that contradict their linked records (DQ-RW-001)
  • OpenLR: whether it is present; structured OpenLR is decoded and its coordinates checked as WGS 84
  • Star-level ceilings per criterion of the TISA RTTI 5-Star Rating Specification for roadworks and closures, from a single file

Privacy

The DATEX II file you open is read and analysed in your browser. It is not uploaded or stored. The viewer sets no cookies, stores nothing in your browser and uses no analytics.

To show the map and look up roads, your browser contacts these services directly. Like every web server, they see your IP address.

  • GitHub Pages (graphmasters.github.io): the app and the map style.
  • OpenFreeMap (tiles.openfreemap.org): map tiles. The map moves to your records and matching reads tiles along a record, so these requests show roughly where your records are.
  • BKG basemap.de (sgx.geodatenzentrum.de): fonts and map icons.
  • OpenStreetMap API (api.openstreetmap.org) and Overpass (overpass-api.de by FOSSGIS e.V., overpass.private.coffee): when you select a road or a record is matched, an OpenStreetMap way id or a small bounding box with a road class.

No other data from your file is sent. The viewer is published by Graphmasters GmbH, see the Impressum.
