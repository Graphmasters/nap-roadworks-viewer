NAP Roadworks Viewer

Source

Inspect a DATEX II roadworks feed

Open or drop a DATEX II XML file (v2 or v3, plain or gzip-compressed), for example a roadworks or closure publication downloaded from a National Access Point.

The file is processed in your browser and is not uploaded. Only when you look up an OpenStreetMap road is its way id sent to the OSM API; map tiles come from OpenFreeMap.

What it checks
  • XML well-formedness, DATEX II version, publication type, namespaces and extensions
  • XSD validation against schema files you select
  • Heuristic profile checks (MDM roadworks profile, NDW)
  • Roadworks and closures with line geometry on the map; other location types are listed with a reason
  • Lane status (laneStatusCoded) against OSM lane tags
  • Closures that contradict their linked records (DQ-RW-001)
