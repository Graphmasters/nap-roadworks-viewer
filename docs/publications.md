# Publications

## Is this road really closed?

*NAP Roadworks Viewer: check DATEX II roadworks feeds and link them to the road network, lane by lane*

Dr. Jonas Matthias, Graphmasters GmbH. Poster, NAPCORE Mobility Data Days, Athens, 25–26 November 2026.

[Poster (PDF, ISO A2, 1.8 MB)](https://graphmasters.github.io/presentations-jonas/nap-roadworks-poster/poster_nap-roadworks-viewer_jonas_matthias_graphmasters.pdf){ .btn .btn-primary }
[Poster page](https://graphmasters.github.io/presentations-jonas/nap-roadworks-poster/){ .btn .btn-outline-primary }

> NAP Roadworks Viewer is an open-source browser tool that checks DATEX II roadworks and closure feeds
> from National Access Points: schema and profile checks, selected TISA RTTI 5-Star criteria,
> OpenStreetMap matching and lane-level passability. It also flags conflicting records, e.g. a road
> closure whose linked cause only prohibits stopping/parking.

**Topics:** DATEX II; data quality; roadworks and road closures; TISA RTTI 5-Star; OpenStreetMap;
open-source NAP tools.

The poster walks from a DATEX II file through the four steps
[check, locate, interpret and routing hint](index.md#from-feed-to-road-in-four-steps), shows two cases
from a published feed ([restricted is not closed](matching-lanes.md#example-restricted-is-not-closed)
and [closed or not?](passability.md#dq-rw-001-closure-that-contradicts-its-cause)), and explains the
[RTTI 5-Star ceilings](rtti.md#typical-problems-and-their-fixes) with typical problems and their fixes.
